# flutter_curves

Интерактивная площадка для кривых анимации Flutter.

На экране рисуется график `Curve` — сетка, оси, контрольные точки и точка,
бегущая по кривой, — а по обе стороны от него идут два ряда маленьких
анимированных плиток. Каждая плитка проигрывает ту же кривую за то же
время, но по-своему: сдвиг, масштаб, поворот, скос, прозрачность, цвет,
скругление или сырая матрица. Смысл в том и есть — видеть график и десяток
анимаций от одного контроллера рядом.

## Что можно делать

- Выбрать кривую из полного каталога `Curves` и нескольких собранных
  вручную вариантов `ThreePointCubic`.
- Задать `Cubic` четырьмя слайдерами, а `ElasticIn/Out/InOut` — типом и
  периодом. График, слайдеры и плитки остаются согласованными, что бы из
  них ни двигали.
- Выставить время анимации и паузу между прогонами.
- Перевернуть кривую на обратном ходе и сравнить `curve.flipped` с
  исходной.
- Нажать на любую плитку и заменить моушен в ней другим.
- Переключить светлую и тёмную темы.

## Запуск

```sh
flutter pub get
flutter run
```

## Требования

Пол SDK в `pubspec.yaml` — Dart 3.13, то есть тулчейн эпохи Flutter 3.35
или новее.

Одна зависимость, `auto_scroll_band`, — локальный пакет по относительному
пути из соседнего каталога, поэтому отдельно взятый клон не соберётся,
пока его нет рядом с этим репозиторием. Состоянием управляет
[scopo](https://pub.dev/packages/scopo), он берётся с pub.dev.
